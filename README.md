# 咪的喂食器

一个给女朋友点餐用的微信小程序启动项目。首版使用原生微信小程序结构，支持浏览菜单、选择菜品、填写口味备注、生成点餐单并复制给对方。

## 本地验证

```bash
npm test
```

## 本地检查

```bash
npm run check
```

这个命令会执行 JS 语法检查、小程序配置检查和全部 Node 测试。

## 启动小程序

1. 打开微信开发者工具。
2. 选择“导入项目”，目录选择本仓库根目录。
3. 如果没有正式 AppID，使用测试号导入。
4. 编译后进入“咪的喂食器”首页。

## 测试主人端

1. 在小猫端选择餐次、状态和菜品。
2. 点击“生成点餐单”，确认订单已生成。
3. 回到首页，点击顶部的“主人端测试”。
4. 在主人端依次点击“主人收到啦”、“开始做饭”、“做好了，叫咪来吃”。

## 当前功能

- 暖黑风格的小猫端点餐首页。
- 午饭 / 晚饭 / 夜宵餐次选择。
- 食欲 + 情绪状态选择。
- 菜品多选、搜索和愿望菜入口。
- 本地 mock API 生成最近点餐单。
- 点餐结果页展示订单明细和备用复制文案。
- 开发态主人端可查看当前订单，并完成接单、开始做饭、做好饭流程。
