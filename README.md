# 咪的喂食器

一个给女朋友点餐用的微信小程序启动项目。首版使用原生微信小程序结构，支持浏览菜单、选择菜品、填写口味备注、生成点菜单、发送给主人、查看状态和一键复点。

## 本地验证

```bash
npm test
```

## 本地检查

```bash
npm run check
```

这个命令会执行 JS 语法检查、小程序配置检查和全部 Node 测试。

## 启动小程序

1. 打开微信开发者工具。
2. 选择“导入项目”，目录选择本仓库根目录。
3. 如果没有正式 AppID，使用测试号导入。
4. 编译后进入“咪的喂食器”首页。

## 测试主人端

1. 在小猫端选择餐次、状态和菜品。
2. 点击“生成点菜单”，进入预览页后再点击“发送给主人”。
3. 回到首页，点击顶部的“主人端测试”。
4. 在主人端依次点击“主人收到啦”、“开始做饭”、“做好了，叫咪来吃”。
5. 回到小猫端首页，点击“看小愿望状态”，确认状态已经同步更新。
6. 回到首页点击“吃过的”，确认完成订单进入历史，并可点击“再来一份”生成新的点菜单草稿。
7. 在主人端点击“菜单维护”，新增、编辑或隐藏菜品，确认小猫端只看到未隐藏的菜。

## 当前功能

- 暖黑风格的小猫端点餐首页。
- 午饭 / 晚饭 / 夜宵餐次选择。
- 食欲 + 情绪状态选择。
- 菜品多选、搜索和愿望菜入口。
- 点菜单草稿预览和单独“发送给主人”流程。
- 点餐结果页展示订单明细、当前中文状态和备用复制文案。
- 小猫端可回看最近点餐状态，主人端更新后会刷新显示。
- 小猫端历史订单和一键复点。
- 开发态主人端可查看当前订单，并完成接单、开始做饭、做好饭流程。
- 开发态主人端可新增、编辑、隐藏和恢复菜品。
